Download for Windows

Three steps

macOS

  1. Install LaTeX: brew install --cask mactex-no-gui
  2. Open the .dmg and drag SponsorJobs to Applications.
  3. On first open, go to System Settings, Privacy & Security, Open Anyway.

Windows 10 or later

  1. Install LaTeX with MiKTeX.
  2. Run SponsorJobs-Setup.exe.
  3. If SmartScreen warns, click More info, then Run anyway.

The installers are not code-signed yet, which is why your system asks. Linux or an Intel Mac: run it from source.
